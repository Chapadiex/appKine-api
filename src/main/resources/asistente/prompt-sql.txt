Consulta SQL de solo lectura sobre las vistas del centro (PostgreSQL). Sirve para listados, conteos y totales que ninguna otra herramienta responde. Entrada: sql, una sola sentencia SELECT (puede empezar con WITH); nunca escribe.

Reglas:
- Usá SOLO estas vistas y columnas. Ya están filtradas al centro y a la sede: no agregues filtros de organización ni de sede.
- Para "hoy" usá fecha = CURRENT_DATE; para "este mes", date_trunc('month', fecha) = date_trunc('month', CURRENT_DATE); para "esta semana", date_trunc('week', fecha) = date_trunc('week', CURRENT_DATE).
- Para buscar a una persona por nombre usá lower(apellido) LIKE lower('%texto%') o lower(nombre) LIKE lower('%texto%').
- Poné alias en castellano y legibles a las columnas calculadas (AS cantidad, AS total).
- Devuelve como máximo 50 filas: en un listado ordená y poné LIMIT 50.
- Filtrá por estado solo si la pregunta lo pide (atendidos, cancelados, ausentes).
- Funciones permitidas: count, sum, avg, min, max, coalesce, nullif, round, lower, upper, trim, concat, length, date_trunc, date_part, extract, age, now, to_char, string_agg, row_number, rank. No uses otras.
- Si el motor devuelve un error (columna inexistente, tipos), corregí la consulta y reintentá.
- Para el nombre de una persona, un profesional o un servicio, uní por su id (personas.persona_id, profesionales.profesional_id, servicios.servicio_id).

Vistas:
personas(persona_id, apellido, nombre, fecha_nacimiento, edad, activa, es_paciente, paciente_desde, alta_en)
  -- el padrón. Un "paciente" es una persona con es_paciente = true.
coberturas(cobertura_id, persona_id, tipo, financiador, financiador_tipo, plan, principal, vigencia_desde, vigencia_hasta, activa)
  -- obra social o prepaga de cada persona. tipo: FINANCIADA (obra social o prepaga) o PARTICULAR.
profesionales(profesional_id, apellido, nombre, rol, sede_id, activo)
  -- rol: ORG_ADMIN, CONSULTORIO_ADMIN, PROFESIONAL, ADMINISTRATIVO.
servicios(servicio_id, nombre, modalidad, duracion_minutos, capacidad, precio_base, moneda, admite_obra_social, activo)
turnos(turno_id, persona_id, servicio_id, profesional_id, inicio, fin, fecha, estado, sobreturno, origen, cancelado_en, llegada_en)
  -- estado: RESERVADO, CONFIRMADO, PRESENTE, EN_ATENCION, ATENDIDO, AUSENTE, RETIRADO, CANCELADO.
sesiones(sesion_id, persona_id, turno_id, caso_id, servicio_id, profesional_id, estado, modo, asistencia, numero_sesion, iniciada_en, cerrada_en, fecha)
  -- atenciones registradas. estado: BORRADOR, CERRADA.
casos(caso_id, persona_id, numero_caso, servicio_id, estado, abierto_en, cerrado_en)
  -- casos clínicos. estado: ACTIVO o CERRADO.
clases(clase_id, titulo, servicio_id, profesional_id, inicio, fin, fecha, capacidad, cupo_ocupado, estado)
inscripciones(inscripcion_id, clase_id, persona_id, estado, inscripto_en, cancelada_en)
asistencias_clase(asistencia_id, clase_id, persona_id, resultado, registrada_en)
  -- resultado: PRESENTE, PRESENTE_TARDE, AUSENTE.
deudas(deuda_id, persona_id, responsable, financiador, concepto, importe_original, saldo, moneda, estado, devengada_en, fecha)
  -- responsable: PACIENTE o FINANCIADOR. estado: PENDIENTE, PARCIAL, PAGADA, ANULADA. "Lo que deben" es sum(saldo) con estado PENDIENTE o PARCIAL.
cobros(cobro_id, persona_id, total, moneda, saldo_a_favor, cobrado_en, fecha, anulado)
  -- excluí los anulados (anulado = false) salvo que pregunten por ellos.
movimientos_caja(movimiento_id, fecha, tipo, medio, importe, moneda, concepto, registrado_en)
  -- tipo: INGRESO, EGRESO, REVERSION_DE_INGRESO, REVERSION_DE_EGRESO. medio: EFECTIVO, TRANSFERENCIA, TARJETA_DEBITO, TARJETA_CREDITO, OTRO.
egresos(egreso_id, categoria, beneficiario, concepto, importe_total, saldo_pendiente, moneda, estado, registrado_en, fecha)
financiadores(financiador_id, nombre, tipo, activo)
sedes(sede_id, nombre, alias, ciudad, provincia, zona_horaria, agenda_habilitada, activa)
  -- todas las sedes del centro (no solo la activa).
espacios(espacio_id, nombre, tipo, capacidad, vigente_desde, vigente_hasta, activo)
  -- boxes y salas. tipo: BOX, GIMNASIO, GABINETE, SALA_GRUPAL, PILETA, OTRO.
jornadas_caja(jornada_id, fecha, moneda, estado, saldo_inicial, saldo_arqueo, saldo_teorico_cierre, saldo_declarado, diferencia, motivo_diferencia, abierta_en, cerrada_en)
  -- una por día y moneda. estado: ABIERTA o CERRADA. "¿Está abierta la caja?" = estado = 'ABIERTA' AND fecha = CURRENT_DATE.
presentaciones(presentacion_id, financiador_id, financiador, numero, periodo_desde, periodo_hasta, estado, moneda, total_presentado, total_debitado, total_cobrado, saldo, creada_en, presentada_en, facturada_el, conciliada_en, anulada_en)
  -- liquidaciones o lotes a obras sociales. estado: BORRADOR, PRESENTADA, FACTURADA, CONCILIADA, ANULADA. "Enviada" = presentada_en no nulo.
presentacion_items(item_id, presentacion_id, deuda_id, persona_id, sesion_id, fecha_prestacion, concepto, estado, importe_presentado, importe_debitado, motivo_debito, incluido_en)
  -- estado: INCLUIDO, ACEPTADO, ACEPTADO_PARCIAL, DEBITADO, DEBITADO_PARCIAL, ANULADO.
pagos_financiador(pago_id, financiador_id, financiador, presentacion_id, importe, moneda, medio, fecha, registrado_en)
pagos_egreso(pago_id, egreso_id, fecha, importe, moneda, medio, estado, anulado, pagado_en, anulado_en)
  -- pagos de egresos (proveedores, alquiler, honorarios). Uní con egresos por egreso_id; el proveedor es egresos.beneficiario. Excluí anulado = true.
liquidaciones_honorarios(liquidacion_id, profesional_id, egreso_id, periodo_desde, periodo_hasta, importe_total, moneda, estado, confirmada_en, liberada_en)
  -- honorarios de profesionales. estado: VIGENTE o LIBERADA.
liquidaciones_honorarios_clase(detalle_id, liquidacion_id, clase_id, profesional_id, fecha, titulo, servicio_id, servicio, presentes, instructores, importe_por_participante, importe_clase, importe_colaborador, moneda)
practicas(practica_id, codigo, nombre, global, activa)
convenios(convenio_id, financiador_id, financiador, plan, codigo, nombre, modalidad, moneda, vigencia_desde, vigencia_hasta, requiere_orden, requiere_autorizacion, requiere_credencial, limite_sesiones_mensual, activo)
aranceles(arancel_id, convenio_id, convenio, financiador, plan, practica_id, practica_codigo, practica, servicio_id, importe_total, importe_financiador, coseguro, moneda, vigencia_desde, vigencia_hasta, activo)
  -- importe_total = importe_financiador + coseguro (el coseguro lo paga el paciente).
ordenes_medicas(orden_id, persona_id, cobertura_id, financiador, medico, fecha_emision, sesiones_prescriptas, vigencia_desde, vigencia_hasta, activa)
autorizaciones(autorizacion_id, persona_id, orden_id, financiador, practica_id, practica, convenio, estado, cantidad_autorizada, cantidad_consumida, saldo, vigencia_desde, vigencia_hasta, activa)
  -- estado: PENDIENTE, APROBADA, OBSERVADA, RECHAZADA. saldo = autorizadas - consumidas.
lista_espera(espera_id, persona_id, servicio_id, profesional_id, caso_id, fecha_desde, fecha_hasta, dias_semana, hora_desde, hora_hasta, prioridad, estado, turno_id, creada_en, cerrada_en)
  -- estado: ACTIVA, ASIGNADA, DESCARTADA. prioridad: NORMAL, ALTA, URGENTE.
recepciones(recepcion_id, turno_id, persona_id, estado, modalidad, practica_id, llegada_en, fecha, validada_en, en_espera_desde, llamada_en, cerrada_en)
  -- llegadas del día. estado: LLEGO, VALIDADA, OBSERVADA, EN_ESPERA, LLAMADA, CERRADA, ANULADA, RETIRADO. modalidad: COBERTURA o PARTICULAR.
productos(producto_id, nombre, tipo, servicio_id, creditos, precio, moneda, vigencia_dias, vigencia_desde, vigencia_hasta, activo)
  -- tipo: PACK o ABONO.
pases(pase_id, persona_id, producto_id, producto, tipo, servicio_id, precio, moneda, creditos_iniciales, creditos_usados, creditos_disponibles, vigencia_desde, vigencia_hasta, estado, renovacion_automatica, vendido_en, anulado_en)
  -- packs y abonos vendidos. estado: ACTIVO, AGOTADO, VENCIDO, ANULADO.
feriados(feriado_id, fecha, nombre, tipo, cierra_la_sede)
disponibilidad(disponibilidad_id, profesional_id, dia_semana, hora_desde, hora_hasta, vigencia_desde, vigencia_hasta, activa)
  -- horario semanal del profesional. dia_semana: 1 = lunes ... 7 = domingo.

Ejemplos:
- ¿cuántos pacientes tenemos? -> SELECT count(*) AS pacientes FROM personas WHERE es_paciente AND activa
- ¿qué obras sociales tienen más pacientes? -> SELECT financiador, count(DISTINCT persona_id) AS pacientes FROM coberturas WHERE activa AND financiador IS NOT NULL GROUP BY financiador ORDER BY pacientes DESC LIMIT 50
- ¿quién nos debe más plata? -> SELECT p.apellido, p.nombre, sum(d.saldo) AS deuda, d.moneda FROM deudas d JOIN personas p ON p.persona_id = d.persona_id WHERE d.responsable = 'PACIENTE' AND d.estado IN ('PENDIENTE', 'PARCIAL') GROUP BY p.apellido, p.nombre, d.moneda ORDER BY deuda DESC LIMIT 50
- ¿está abierta la caja? -> SELECT CASE WHEN EXISTS (SELECT 1 FROM jornadas_caja WHERE fecha = CURRENT_DATE AND estado = 'ABIERTA') THEN 'abierta' ELSE 'cerrada' END AS caja_de_hoy
- ¿qué packs vendimos este mes? -> SELECT producto, tipo, count(*) AS vendidos, sum(precio) AS total, moneda FROM pases WHERE estado <> 'ANULADO' AND date_trunc('month', vendido_en) = date_trunc('month', now()) GROUP BY producto, tipo, moneda ORDER BY vendidos DESC LIMIT 50
